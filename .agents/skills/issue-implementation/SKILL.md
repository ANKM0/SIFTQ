# Issue Implementation

Use this skill for SIFTQ issue implementation work.

## Flow

1. Read `docs/contributing/branch-strategy.md`.
2. Read `docs/contributing/commit-message-format.md`.
3. Read `docs/contributing/pull-request.md`.
4. Implement the issue with minimal scoped changes.
5. Run the smallest meaningful validation first, then broader gates as needed.
6. Commit with the documented format.
7. Prepare PR title/body with the documented template.

## Rules

- Keep unrelated changes out of the commit.
- Do not revert user changes without explicit request.
- Mention skipped or failed validation.
