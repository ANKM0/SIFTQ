# ADR 0051 第1段階検証: レビュー基準比較

## 結論

同じ既存ADR 11件に対し、旧 `adr-review` 基準とADR 0051適用後の基準を比較した。

- 旧基準: 実装詳細を30件検出、該当ADRは8/11件
- 新基準: 意味的な検証不足・過大主張を34件追加で検出、該当ADRは11/11件
- 新基準は、旧基準では扱わなかった根拠不足・比較検証不足を追加で表面化した
- 方針適用により実際の誤適用が減ったこと、レビューコストが許容範囲であることは未検証

したがって、ADR 0051の効果仮説を確認済みとはせず、**追加の検証論点を検出できることを示した探索的結果**とする。

## 条件

| 項目 | 条件 |
| --- | --- |
| 対象 | ADR 0003、0007、0008、0012、0018、0028、0035、0038、0039、0043、0050 |
| 除外 | ADR 0051。評価対象方針自身の循環評価を避けるため |
| 旧基準 | 5af1f06直前の `adr-review`。実装詳細のみを判定 |
| 新基準 | 現行 `adr-review`。実装詳細に加え、根拠・主張範囲・比較検証を判定 |
| 実施方法 | 各基準を独立したレビューセッションで同じADR群へ適用 |
| 正解ラベル | 作成していない。検出数はレビュアーの指摘数であり、真陽性率ではない |

## 結果

| ADR | 旧: 実装詳細 | 新: 意味的な指摘 |
| --- | ---: | ---: |
| 0003 | 0 | 8 |
| 0007 | 0 | 1 |
| 0008 | 3 | 2 |
| 0012 | 3 | 2 |
| 0018 | 0 | 3 |
| 0028 | 1 | 3 |
| 0035 | 2 | 2 |
| 0038 | 8 | 3 |
| 0039 | 5 | 2 |
| 0043 | 5 | 5 |
| 0050 | 3 | 3 |
| **合計** | **30** | **34** |

## 代表的な検出

- ADR 0038・0039: 性能、ページ件数、操作配置、境界変動を別の主張として扱う必要を検出した。
- ADR 0043: 観測値からstep削除の効果を主張するには、測定方法・比較条件・範囲が不足していることを検出した。
- ADR 0003・0035・0050: 速度、使いやすさ、必要性、利用負担などの比較主張に条件や証拠が不足していることを検出した。

## 限界

- 旧基準と新基準でレビューセッションを分けたため、レビュアー差を除去していない。
- 独立した正解ラベルがなく、指摘数の増加を検出精度の向上とは解釈できない。
- 対象は内容を選んだ11件であり、全ADRへの一般化はできない。
- レビュー時間、費用、修正回数、実際の誤適用は測定していない。
