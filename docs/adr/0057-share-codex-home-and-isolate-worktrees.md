# ADR 0057: Codex homeを共有しworktreeで作業対象を分離する

## 決定

- 通常のtaqt実行では共有のCodex homeを使い、作業対象はworktreeの実行コンテキストで分離する。
- 診断など明示的な用途に限り、Codex homeのoverrideを許可する。

### 決定の理由

- skills、認証、plugins、session履歴を一箇所に保ちつつ、編集対象だけをworktree単位で分離するため。
- 通常実行と診断実行の境界を明確にするため。

## 不採用

- worktreeごとにCodex homeを持つ方式
  - 共通設定と履歴が分散し、生成時の競合要因になるため。
- Dockerだけで作業対象を分離する方式
  - home共有と編集対象分離の責務が不明確になるため。

## 補足情報

### 背景

- ADR 0015から、作業対象の分離とモデル選択を別の判断として記録する。

### 制約事項

- 認証やsession情報をworktreeへ複製しない。
- 作業対象の分離はGit worktreeと実行コンテキストが担う。
