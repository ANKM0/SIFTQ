# ADR 0028: Adopt common UI state and feedback rules

## 決定

- 全画面で「通常 / 空 / ローディング / エラー」の 4 状態を定義する。
- ローディングは初期取得中・送信中・削除中・DnD 確定中を区別する。
- 成功・軽い通知は 3 秒 + 手動で閉じるボタン。
- 操作が必要なエラーは自動で消さず、明示的に閉じるまで残す。

### 決定の理由

- 画面ごとに状態や通知の挙動がぶれるのを防ぐ。
- 曖昧な「数秒後」を排除し、アクセシビリティと操作感を安定させる。

## 不採用

- 画面ごとに個別の状態・通知ルールを定義
  - 実装と検証が不統一になるため。

## 補足情報

### 背景

- ADR 0018 の HTML 駆動 UI に共通の UX 仕様を乗せる。

### 制約事項

- 各画面の 4 状態の中身と通知の配置は実装時に決める。
