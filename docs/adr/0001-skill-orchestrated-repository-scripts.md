# ADR 0001: SkillとScriptの使い分け方針について

## 目的
<!-- 解決したい課題はXXX。 -->

skills と scripts の責務境界を明確にすることで、設計実装時に迷いをなくすこと

## 背景
<!-- 解決する問題の背景やチームの状況などの戦略。 -->

skills と scripts の責務境界が不明瞭なため
レポジトリ内でskillsとscriptの実装の粒度がバラバラになっていた。

## 制約事項
<!-- ライブラリや設計の変更におけるトレードオフやできない事とその理由。 -->

なし

## 内容

### 採用した内容
<!-- 採用した内容とその理由を記載 -->

- それぞれの責務は、Skillは判断とorchestration。 Scriptは再現可能な操作。 skill-localのscriptはskill自体の補助とする。
  - 上記の方法が却下した内容と比べて、再利用性と柔軟性のバランスが取れていると考えたため

### 採用しなかった内容
<!-- 採用しなかった内容とその理由を記載 -->

- skillsのみ使用してscriptsを作成しない
  - 機械的に判断できるものは、再利用するためにscriptsにした方がよいため却下
- scriptsのみ使用してskillsを作成しない
  - scriptだけでは、状況による判断ができないため却下
