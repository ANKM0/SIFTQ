# ADR 0051: ADRの判断根拠と検証記録の運用を定める

## 決定

- ADRには、将来ほかの判断とは独立して撤回・変更でき、継続して参照する横断的な意思決定を記録する。
- 一つの意思決定を、独立して間違え得る主張へ分解する。各主張について、根拠の種類、確認範囲、状態を記録する。
- 性能、費用、使いやすさ、必要性、優劣などの経験的な主張には、現行案と候補案を同一条件で比較する。比較できない場合は未検証の暫定判断とする。
- 要求・規格への適合、既存方針の適用、論理的な必須性は、比較実験ではなく適合確認・テスト・証明で確認する。
- 局所的な判断は、実装・作業・実験の記録に残し、必要に応じて共通のADRを参照する。
- ADRには判断、理由、不採用案、根拠の種類、結果要約、限界、再検討条件、証拠への参照を残す。詳細な結果や再現手順は実験記録に置く。

### 決定の理由
- 判断を独立した主張へ分解し、主張ごとの検証範囲を記録する形式を採用すると、判断の境界を明示できるため。
- 根拠の種類に応じて検証方法を選ぶと、要件適合と代替案への優位性を別の主張として扱えるため。
- 未検証の判断を暫定扱いにすると、不確実性と再検討条件を記録できるため。

### 判断ごとの根拠と検証
| 判断・主張 | 根拠の種類 | 検証・確認 | 状態 |
| --- | --- | --- | --- |
| ADRの粒度は、独立して撤回・変更でき継続参照する判断とする | 既存のADR運用 | 運用方針として採用 | 確認済み |
| 経験的な優劣・必要性は比較検証する | 検証方針 | 同一条件の比較、または未検証の暫定判断 | 確認済み |
| 要件適合は比較実験を必須としない | 検証方針 | 要求・規格との適合確認、テスト、証明 | 確認済み |
| 局所的な判断は局所記録に残す | 既存のADR運用 | 実装・作業・実験の記録からADRを参照 | 確認済み |
| 詳細な結果と再現手順は実験記録に置く | 既存のADR運用 | ADRには要約と参照を残す | 確認済み |
| 判断の分解で検証結果の誤適用を減らせる | 未検証の仮説 | 新規ADRのレビューで誤適用の発生を観測する | 暫定 |
| 根拠の種類の分類で適合と優位性の混同を減らせる | 未検証の仮説 | ADRレビューで分類誤りの発生を観測する | 暫定 |

表の「確認済み」は方針として採用したことを示し、運用効果の実証を意味しない。

### 検証結果

既存ADR 11件を旧基準と新基準で比較レビューした。旧基準は実装詳細を30件、新基準は意味的な検証不足・過大主張を34件追加で検出した。新基準が追加の検証論点を表面化したことは確認できたが、誤適用の減少、検出精度、レビューコストは未検証である。

## 不採用

- すべての判断で代替実装の比較実験を必須にする
  - 要求・規格への適合確認や論理的な証明で足りる判断まで、不要な実験コストを課すため。
- 根拠の記載だけで検証済みと扱う
  - 性能・優劣・必要性など、測定しなければ分からない主張の不確実性を隠すため。
- Accepted済みADRを新方針に合わせて一括修正する
  - 過去の判断記録を変更し、当時の判断と現在の評価を混同するため。

## 補足情報

### 背景

- ADRの決定理由には、要求、観測、仮説、代替案との比較結果が混在しやすい。
- 方式の検証結果が、件数や配置など別の判断まで正当化したように扱われると、後から判断を個別に見直せない。

### 制約事項

- 実験の詳細はADRに全文を記載せず、実験記録へ分離する。
- 既存のAccepted済みADRは変更せず、新規または変更する判断から適用する。

### 限界と再検討条件

- 限界: ADRレビューによる根拠や検証要否の判断には、人による確認が残る。第1段階の比較は正解ラベル、同一レビュアー条件、運用効果を測定していない。
- 再検討条件: ADRの粒度が局所的な判断まで過度に拡大する、または検証記録のコストが判断の価値を継続的に上回る場合。
