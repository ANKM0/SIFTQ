# ADR 0039: Task一覧のページングUIはGitHub issue一覧と同様にする

## 決定

- ページ切替UIはページ番号＋前へ/次へとする。
- ページ番号が枠に収まらない場合は、先頭・末尾を残し、先頭/末尾と中間の間を「…」で省略する。
- statusを切り替えた場合は1ページ目に戻す。
- ページナビの配置は一覧下のみとする。

### 決定の理由

- 番号指定により任意ページへ直接移動でき、件数増加時も位置を把握できるため。
- 省略規則により、ページ数増加時の横幅圧迫とスマホでのタップしづらさを抑えられるため。
- status切替で1ページ目に戻すことで、存在しないページ指定などの矛盾した表示を避けられるため。
- 一覧下のみの配置で、既存の画面構成（status filterが上）との役割分担が明確になるため。

## 不採用

- 前へ/次へ＋件数表示のみ（番号なし）
  - 3ページ以上ある場合の直接ジャンプができないため。
- スマホ専用の別画面・別操作
  - ADR 0038の制約どおり、利用実態を見て別途検討するため。Issueは現時点では作成しない。

## 補足情報

### 背景

- Task一覧に25件固定のページングを導入する（Issue #369、ADR 0038）。

### 制約事項

- 省略規則: 先頭ページと最終ページは常に表示し、カレントの前後1件を表示する。飛んだ区間は「…」にまとめる。
- 25件以下（1ページ）の場合はページナビ自体を表示しない。
- ページ指定は`?page=`、statusは`?status=`を維持する。
