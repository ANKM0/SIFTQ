SIFTQ UI Wireframes

マトリックスとタスク管理の画面状態と遷移関係

マトリックス タスク一覧
Matrix: Empty 空 area は中央の + から作成を開始する。 Matrix: Create 対象 area で title を入力する。 Matrix: Cards 作成済み card、count、title と Edit action。 Matrix: Editing Edit action から title / description edit modal を開く。 Matrix: Dragging area 内並び替え、matrix area 間移動、terminal area drop。 Matrix: Terminal Drop Done / Skipped drop 後は matrix から非表示。 タスク一覧 全taskをlistOrder順のカードで表示する。 選択あり一覧 checkbox 選択と一括削除 enabled 状態。 一括削除確認 選択件数を確認し、キャンセルか削除を選ぶ。 一括削除後一覧 選択したタスクを削除しました通知を表示する。 一覧並び替え DnDでlistOrderだけを更新する。 ステータス選択 active / done / skipped を選択する。 タスク詳細 title、description、area、status、日時を確認・編集する。 削除確認 削除前に確認し、実行後は一覧へ戻る。 削除後一覧 削除成功通知を一覧上に表示する。 タスク未検出 存在しないtask詳細URLの404状態。

マトリックス

状態 確認したいこと 次の遷移
Empty No cards を出さず、空 area に + を置く。 + click → Create
Create 入力欄、disabled、error、作成位置。 Create success → Cards
Cards card 表示、Edit action、area 内表示順、長い title。 Edit → Editing / drag start → Dragging
Editing title / description edit modal、Save、Cancel、invalid title の disabled。 Save / Cancel → Cards
Dragging drag 中、area 内並び替え、matrix area 間移動、drop target。 Drop on matrix → Cards / Drop on terminal → Terminal Drop
Terminal Drop Done / Skipped に count を出さず、drop 後 card を matrix から消す。 次操作待ち。復元 UI は提供しない。

タスク管理

状態 確認したいこと 次の遷移
タスク一覧 全taskをdraggable list cardで表示し、title、description、area、statusを確認する。 詳細 → タスク詳細 / ステータス → ステータス選択 / 削除 → 削除確認 / drag → 一覧並び替え / checkbox → 選択あり一覧
選択あり一覧 checkbox 選択、選択件数、一括削除 button の enabled state を確認する。 一括削除 → 一括削除確認 / checkbox toggle → タスク一覧
一括削除確認 選択件数を含む確認とキャンセル時の選択維持を確認する。 削除 → 一括削除後一覧 / キャンセル → 選択あり一覧
一括削除後一覧 選択したタスクを削除しました通知を出し、選択状態を空にする。 次操作待ち
一覧並び替え 全task DnDがlistOrderだけを更新し、Matrixのarea/orderへ影響しない。 Drop → タスク一覧
ステータス選択 status buttonから active / done / skipped の選択肢を表示する。 status選択 → タスク一覧
タスク詳細 title、description、area、statusを編集し、作成日時 / 更新日時をreadonly表示する。 一覧へ戻る / 保存 → タスク一覧 / 削除 → 削除確認
削除確認 物理削除前にtask titleを含む確認を表示する。 削除 → 削除後一覧 / キャンセル → タスク一覧
削除後一覧 削除成功通知を出し、復元操作は提供しない。 次操作待ち
タスク未検出 存在しないtask詳細URLを開いた404状態から一覧へ戻れる。 タスク一覧へ戻る → タスク一覧
Task List 縦並び draggable list、status menu、詳細、削除、空 description 表示。 Drag / status / detail / delete → 各状態。
Task Detail title、description、area、status、readonly timestamps。 Back / Save / Delete / Not found → Task List。
