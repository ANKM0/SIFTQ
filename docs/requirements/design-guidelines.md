# UI カラー & デザインガイド

## 目的

画面ごとに色を場当たり的に決めず、配色の意図と検証基準を1か所に定める。
この文書は色の指針のみを扱い、レイアウトやコンポーネント構造は扱わない。

## 配色方針

配色は **ニュートラル（黒〜白のグレー） + 緑1色** のみで構成する。
青・紫・黄・赤は使わない。装飾目的の色も持たない。

5スロットで定義する。

| スロット | 値 | 役割 |
| --- | --- | --- |
| Ink | `#1b1f24` | 主要文字、強い境界 |
| Chrome | `#ffffff` | トップバーのみ（例外） |
| Surface | `#e6e9ee` / `#d5dae1` / `#f1f3f6` | 面（カード・コンテナ・入力） |
| Border | `#d0d7de` / `#8b949e` | 境界、区切り |
| Green | `#1f883d` | 唯一の機能色（主要アクション、done、working） |

## ニュートラル（Slate）

構造（背景・面・境界・文字）はグレーの明度ランプで表現する。

| トークン | 値 | 用途 |
| --- | --- | --- |
| bg | `#30363d` | ページ背景 |
| surface-sunken | `#d5dae1` | コンテナ（Matrix の枠内、一覧の外枠） |
| surface | `#e6e9ee` | カード、パネル、行、ボタン、モーダル |
| field | `#f1f3f6` | 入力欄・編集領域（面より一段明るい） |
| border | `#d0d7de` | 面と面の境界 |
| border-strong | `#8b949e` | 強調境界、区切り |
| text | `#1b1f24` | 面の上の主要文字 |
| text-muted | `#57606a` | 面の上の補助文字 |
| text-inverse | `#e6e9ee` | 暗背景上の主要文字 |
| text-inverse-muted | `#b1bac4` | 暗背景上の補助文字 |
| chrome | `#ffffff` | トップバーのみ（例外） |

## グリーン

| 用途 | 値 |
| --- | --- |
| 主要アクション（塗り） | `#1f883d`（白文字 4.5:1） |
| 面（tint） | `#dafbe1` |
| tint 上の文字 | `#1a7f37` |
| 境界 | `#2a9147` / `#4ac26b` |

緑は「塗り = アクション」「tint 面 + 緑文字 = done / working」として形で区別する。
同じ緑でも面と字の組を変え、意味を混同しない。

## ステータス表現（色に依存しない）

アクセントが緑1色のため、**形（塗り / 枠 / ドット）とラベル文字** で区別する。

| 対象 | 表現 | 色 |
| --- | --- | --- |
| do | 枠バッジ（強） | Ink 枠 + Ink 文字 |
| done | 塗りバッジ | Green tint 面 + Green 文字 |
| skip | 枠バッジ（弱） | Grey 枠 + muted 文字 |
| working | 緑ドット + 緑枠 + 緑文字 | Green |
| area 1–4 | 中立チップ | Grey 枠 + muted 文字 |
| 選択行 | checkbox + 左の緑バー + 濃いグレー面 | Green + neutral |
| リンク | 常時下線 + 文字色継承 | 色なし |

## サーフェス階層

面の高さは **明度の段差ではなく、境界と陰影** で示す。純白は使わない。

1. `bg` ページ背景（最も暗い）
2. `surface-sunken` コンテナ
3. `surface` カード・パネル・行・ボタン
4. `field` 入力欄・編集領域（最も明るい）

## コントラスト基準

- 通常文字: 4.5:1 以上（WCAG 2.1 AA）
- 大きい文字・UI 部品の境界: 3:1 以上（WCAG 1.4.11）

| 組み合わせ | 比 |
| --- | --- |
| text / surface | 13.6:1 |
| text-muted / surface | 5.3:1 |
| text-inverse / bg | 10.0:1 |
| 白文字 / Green `#1f883d` | 4.5:1 |
| Green 文字 / Green tint | 4.6:1 |
| focus 緑 / surface | 3.7:1 |
| focus 緑 / bg | 2.7:1（不足） |

`focus 緑 / bg` と面・境界の段差は 3:1 に届かないため、色だけに頼らず
下記の非色キューで補う。

## ユニバーサルカラーのルール

- 色だけで意味を伝えない。status には必ずラベル文字を併記する。
- 状態の区別は色相に加え、明度差・境界・形（枠 / 塗り / ドット）でも示す。
- 機能色は緑1色。緑以外を意味に使わない。
- リンクは常時下線（色なし）。ホバー時だけの下線は不可。
- エラー・危険も色に頼らない。太字・テキスト・枠で示す（赤は使わない）。
- フォーカスは **二重リング**（緑の outline + 明色の box-shadow）で、暗背景と面の両方で視認できるようにする。

## 適用メモ

- トップバーだけは `chrome` (`#ffffff`) を維持する。
- 面・境界の段差が 3:1 未満のため、境界は `box-shadow` と形で補う。
- 選択行は薄い tint が 1.1:1 程度のため、checkbox と緑の左バーを必須にする。
- 赤を全廃した。delete は Ink 塗りボタン、エラーは Ink 太字。危険色の慣習を失う代わりに非色キューで担保する。
- 実装は各 `src/styles/*.ts` に値を直書きしている。トークン化（CSS 変数）は将来の課題とする。
