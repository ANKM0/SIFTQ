# UI カラー & デザインガイド

## 目的

画面ごとに色を場当たり的に決めず、配色の意図と検証基準を1か所に定める。
この文書は色の指針のみを扱い、レイアウトやコンポーネント構造は扱わない。

## カラーパレット

配色は **5つの機能色 + ニュートラル（Slate）** で構成する。
機能色は「意味」を持ち、装飾目的では使わない。

| 機能色 | 値 | 用途 |
| --- | --- | --- |
| Green | `#1f883d` | 主要アクション（Create / Save）、done、成功 |
| Blue | `#0969da` | do、情報、リンク、選択 |
| Amber | `#9a6700` | 注意、保留、area の強調 |
| Plum | `#8250df` | working などの特殊カテゴリ |
| Red | `#cf222e` | danger、delete、エラー |

各機能色は面（tint）と文字色をセットで使う。

| 機能色 | tint 面 | 文字・境界 |
| --- | --- | --- |
| Green | `#dafbe1` | `#1a7f37` |
| Blue | `#ddf4ff` | `#0969da` |
| Amber | `#fff8c5` | `#9a6700` |
| Plum | `#fbefff` | `#8250df` |
| Red | `#ffebe9` | `#cf222e` |

## ニュートラル（Slate）

構造（背景・面・境界・文字）は Slate ランプで表現する。

| トークン | 値 | 用途 |
| --- | --- | --- |
| bg | `#30363d` | ページ背景 |
| surface-sunken | `#d5dae1` | コンテナ（Matrix の枠内、`.list` 外枠） |
| surface | `#e6e9ee` | カード、パネル、行、ボタン、モーダル |
| field | `#f1f3f6` | 入力欄・編集領域（面より一段明るい） |
| border | `#d0d7de` | 面と面の境界 |
| border-strong | `#8b949e` | 強調境界、区切り |
| text | `#1b1f24` | 面の上の主要文字 |
| text-muted | `#5a6470` | 面の上の補助文字 |
| text-inverse | `#e6e9ee` | 暗背景上の主要文字 |
| text-inverse-muted | `#9aa4b0` | 暗背景上の補助文字 |
| chrome | `#ffffff` | トップバーのみ（例外） |

## サーフェス階層

面の高さは **明度の段差ではなく、境界と陰影** で示す。純白は使わない。

1. `bg` ページ背景（最も暗い）
2. `surface-sunken` コンテナ（Matrix の枠内、一覧の外枠）
3. `surface` カード・パネル・行・ボタン
4. `field` 入力欄・編集領域（最も明るい）

暗背景の上に純白を置くと輝度差が大きく、グレアと目の疲労の原因になる。
最も明るい面は `field` に留め、階層は `border` と `box-shadow` で補う。

## コントラスト基準

- 通常文字: **4.5:1 以上**（WCAG 2.1 AA）
- 大きい文字・UI 部品の境界: **3:1 以上**
- 実測値（本パレット）

| 組み合わせ | 比 |
| --- | --- |
| text / surface | 13.6:1 |
| text-muted / surface | 4.9:1 |
| text-inverse / bg | 10.0:1 |
| text-inverse-muted / bg | 4.8:1 |
| 白文字 / Green `#1f883d` | 4.5:1 |
| Blue / Blue tint | 4.6:1 |
| Green / Green tint | 4.6:1 |
| Amber / Amber tint | 4.5:1 |
| Plum / Plum tint | 4.5:1 |
| Red / Red tint | 4.7:1 |

`#2da44e`（旧 Green）は白文字で 3.2:1 のため通常文字では使わない。
主要ボタンは `#1f883d` を使う。

## ユニバーサルカラーのルール

- 色だけで意味を伝えない。status には必ずラベル文字を併記する。
- 色覚特性で混同しやすい赤 / 緑の対比を唯一の区別にしない。Blue / Amber / Plum を併用する。
- 機能色は必ず「tint 面 + 濃い同系色文字」の組で使う。面の上に純色を置かない。
- 面の上に純白・純黒を置かない。
- 状態の区別は色相に加え、明度差・境界・形（バッジ等）でも示す。

## 適用メモ

- トップバーだけは `chrome` (`#ffffff`) を維持する。
- 実装は各 `src/styles/*.ts` に値を直書きしている。トークン化（CSS 変数）は将来の課題とする。
