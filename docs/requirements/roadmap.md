# プロダクトロードマップ

v0.x 期間だけ使用する方針文書である。要求・仕様の正本は `requirements-analysis.md`、リリースの技術ルールは `docs/contributing/release.md` とし、本書は方針と移行条件の記録に限定する。

## 初期 MVP の扱い

初期 MVP は変更せず、v0.x の基準点として扱う。

## v0.x の範囲

v0.x に次を含める。

- コア導線
- 画面間の状態整合性
- PC・スマホの主要操作
- 安全な編集・削除
- エラー・競合時のデータ保護
- GitHub 連携（中核価値として v0.x の必須領域に含める。具体的な最小範囲は未決定）

## v1.0 の移行条件

v1.0 は v0.x のコア価値が安定した時点と定義する。

## v1.x の候補

v1.x の候補として次を送る。

- 細かいフィルター
- 一括操作の拡張
- 表示・操作の改善
- ショートカット
- 通知・履歴

## 本書の削除方針

v0.x の開発完了と v1.0 への移行後に本書（`roadmap.md`）を削除する。
